Two Gemini renders of the hand sketch, received 2026-11-19. They are the geometry
and content authority for `glance-areas` (see `../glance-areas-PLAN.md` §1.3, §8).

Drop the files here with these exact names:

| File | Shot | What it pins down |
|---|---|---|
| `mockup-collapsed.png` | Floor "Primeiro", 3 × 3 | 3 columns, portrait tiles 225 × 260 at 768 px, readout top-right, name 22 px, 44 px domain circles with badges, two opening pills + centred chevron |
| `mockup-expanded.png` | Sala expanded | One-column vertical panel, siblings as ~96 px mini-tiles reflowing around it, header strip (temp / humidity / presence / battery | power / energy), SPOTS chips, dimmer group, AC row, cover row with inline downstream |

Measurements taken from the 768 px-wide renders are already transcribed into the
plan's §8 token table — do not re-derive them from the images; if the image and the
table disagree, the image wins and the table gets a correction row in §14.

Do not treat the renders as pixel-perfect: they were produced from a sketch, so
spacing and font sizes drift by a few px. Match the structure and the token table.
